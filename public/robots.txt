# Hashed JS/CSS bundles under /assets/ are intentionally left crawlable so
# Googlebot can render the single-page app. Do not block them.
#
# Multiplayer deep links (?lobby= / ?role=) are intentionally NOT disallowed.
# A robots-disallowed URL can never be crawled, so Google could never read the
# rel=canonical on it — a shared lobby link would then be indexed URL-only with
# "No information is available for this page". Letting it be crawled lets the
# self-referencing canonical in this file fold every variant back into /.
